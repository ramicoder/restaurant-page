# Rami's Restaurant (Tech Portfolio)

🔗 **[Live Preview](https://ramicoder.github.io/restaurant-page/)**

## Overview
A Single Page Application (SPA) built entirely with Vanilla JavaScript and Webpack. This project creatively disguises a software engineering portfolio as a restaurant website. Technical skills, certifications (CS50x, CS50SQL), and academic achievements are served up as "menu items," while professional testimonials are framed as "food critic reviews."

## Features
* **Single Page Application (SPA):** Dynamic tab-switching (Home, About, Menu, Reviews) using Vanilla JavaScript DOM manipulation without reloading the page.
* **Webpack Bundled:** Fully modularized architecture. JavaScript, CSS, and image assets are bundled using Webpack.
* **Creative UI/UX:** Features a custom CSS vertical scrolling review ticker, grid layouts, and a unique tech-as-food metaphor.

## Technologies Used
* **HTML5**
* **CSS3** (Flexbox, Grid, Keyframe Animations)
* **Vanilla JavaScript** (ES6 Modules, DOM Manipulation)
* **Webpack** (npm, style-loader, css-loader, asset management)

## Run Locally
To run this project on your local machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/ramicoder/restaurant-page.git
   ```
2. Navigate into the directory:
   ```bash
   cd restaurant-page
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
*(Or run `npm run build` to generate the production files in the `/dist` folder).*
